# iScale Studio Homepage Build Prompt

## Project Overview
Build a professional homepage for iScale Studio, a Philippines-based company specializing in AI-powered digital solutions. The homepage should position the company as an expert in AI Web & App Development while showcasing comprehensive digital transformation capabilities.

**Primary Goal**: Lead generation through appointment scheduling
**Target Audience**: Philippine businesses seeking AI-powered digital solutions
**Tone**: Professional, innovative, trustworthy, results-driven

---

## Homepage Sections & Design Specifications

### 1. HERO SECTION
**Layout**: Full-width, above-the-fold

**Content Requirements**:
- **Headline**: Bold, attention-grabbing statement emphasizing AI-powered solutions
  - Example: "Transform Your Business with AI-Powered Digital Solutions"
- **Subheadline**: 1-2 sentences explaining value proposition
  - Focus on Philippine market and business transformation
- **Primary CTA**: "Schedule a Consultation" (prominent button)
- **Secondary CTA**: "View Our Solutions" (outlined/ghost button)
- **Hero Visual**: Modern, tech-forward image or animation
  - Suggestions: Abstract AI/digital elements, Philippine business context, or custom illustration

**Design Elements**:
- Clean, modern typography with strong hierarchy
- Gradient or solid background (brand colors)
- Subtle animation on load (optional)
- Mobile-responsive with stacked layout on small screens

## Overall Design Guidelines

### Color Scheme
- **Primary**: Professional, tech-forward colors (blues, purples, or brand colors)
- **Accent**: Complementary color for CTAs and highlights
- **Neutral**: Grays for text and backgrounds
- Ensure sufficient contrast for accessibility

### Typography
- **Headings**: Bold, modern sans-serif font
- **Body**: Clean, readable sans-serif font
- **Hierarchy**: Clear sizing distinction (H1 > H2 > H3 > Body)
- Font weights: Use variety for emphasis

### Spacing & Layout
- Generous white space between sections
- Consistent padding and margins
- Maximum content width: 1200-1400px for readability
- Section breaks: Alternating background colors or dividers

### Visual Elements
- **Icons**: Consistent style throughout (line art or solid)
- **Images**: High-quality, professional, optimized for web
- **Animations**: Subtle, purposeful (fade-ins, scroll animations)
- **Shadows**: Soft, consistent depth

### Responsive Design
- Mobile-first approach
- Breakpoints: Mobile (< 768px), Tablet (768-1024px), Desktop (> 1024px)
- Touch-friendly buttons and spacing on mobile
- Simplified navigation on mobile (hamburger menu)

### Performance
- Optimized images (WebP format preferred)
- Lazy loading for images below the fold
- Minified CSS and JavaScript
- Fast loading time (< 3 seconds)

### Accessibility
- Alt text for all images
- Proper heading hierarchy
- Sufficient color contrast (WCAG AA minimum)
- Keyboard navigation support
- Screen reader friendly
