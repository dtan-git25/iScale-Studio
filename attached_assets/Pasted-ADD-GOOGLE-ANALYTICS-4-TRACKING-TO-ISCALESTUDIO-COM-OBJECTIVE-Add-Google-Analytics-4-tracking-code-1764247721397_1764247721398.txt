## Step 3: Add Google Analytics Code

Insert the following code in the <head> section, preferably near the top after the <meta> tags but BEFORE other <script> tags:
```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-1TSQ46FW5G"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  
  gtag('config', 'G-1TSQ46FW5G');
</script>
```
