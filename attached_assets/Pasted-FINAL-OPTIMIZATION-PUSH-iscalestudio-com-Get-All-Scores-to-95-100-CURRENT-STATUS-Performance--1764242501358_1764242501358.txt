## Issue #4: Forced Reflow (105ms delay)

**Problematic files:**
- `/assets/index-B3U6GNyV.js` - causing 105ms reflow
- `/assets/home-BOVIkHk.js` - causing 105ms reflow

**Cause:** JavaScript is querying geometric properties after style changes.

**Fix:**
Look for code that does this pattern:
```javascript
// BAD - causes forced reflow:
element.style.width = '100px';
const height = element.offsetHeight; // Forces reflow!
element.style.height = height + 'px';

// GOOD - batch DOM reads, then writes:
const height = element.offsetHeight; // Read
element.style.width = '100px';       // Write
element.style.height = height + 'px'; // Write
```

Search your JavaScript for:
- `offsetWidth`, `offsetHeight`
- `getBoundingClientRect()`
- `getComputedStyle()`

And ensure they're not mixed with style changes.

## Issue #6: Third Party Code (Google Fonts)

**Current Load:**
- Google Fonts CDN: 82 KiB

**Optimization Options:**

**Option A: Self-host fonts (fastest):**
```html
<!-- Download fonts and host locally -->
<link rel="preload" href="/fonts/inter-regular.woff2" as="font" type="font/woff2" crossorigin>

<style>
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-regular.woff2') format('woff2');
  font-display: swap;
  font-weight: 400;
}
</style>
```

**Option B: Optimize Google Fonts (easier):**
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap" rel="stylesheet">
```

Make sure `font-display: swap` is in your CSS.
